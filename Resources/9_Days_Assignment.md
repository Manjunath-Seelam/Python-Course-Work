Accept sales information for at least ten products. 
For every product, collect: 
• Product ID 
• Product name 
• Category 
• Quantity sold 
• Unit price 
• Discount percentage 
Perform the following operations: 
• Calculate the total sales amount for every product. 
• Calculate the discount amount for every product. 
• Calculate the final product revenue. 
• Identify the highest revenue-generating product. 
• Identify the lowest revenue-generating product. 
• Calculate the total company revenue. 
• Calculate the average revenue per product. 
• Display the total number of products sold. 
Generate a complete business sales report with properly aligned columns. 
Use all four output techniques wherever appropriate: 
1. Printing multiple values using commas. 
2. Old-style % formatting. 
3. .format() method. 
4. F-string formatting. 
Ensure all monetary values are displayed with two decimal places and all product details are arranged in a 
professional tabular format. 
Concepts to Use: 
• input() function 
• Lists 
• Dictionaries 
• Nested data structures 
• for loops 
• Conditional statements 
• Arithmetic operators 
• sum(), max() and min() functions 
• F-string formatting 
• % formatting operator 
• .format() method 
• String alignment 
• Field width 
• Decimal precision 
• Tabular output formatting
